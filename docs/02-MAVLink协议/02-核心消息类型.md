## 1. 系统消息

### 1.1 HEARTBEAT (ID=0)

心跳消息是最基础的消息，用于检测系统是否在线。

```python
# HEARTBEAT 消息结构
HEARTBEAT = {
    "id": 0,
    "fields": [
        {"name": "custom_mode",    "type": "uint32_t", "description": "自定义飞行模式"},
        {"name": "type",           "type": "uint8_t",  "description": "飞行器类型 (MAV_TYPE)"},
        {"name": "autopilot",      "type": "uint8_t",  "description": "飞控类型 (MAV_AUTOPILOT)"},
        {"name": "base_mode",      "type": "uint8_t",  "description": "基础模式标志"},
        {"name": "system_status",  "type": "uint8_t",  "description": "系统状态 (MAV_STATE)"},
        {"name": "mavlink_version","type": "uint8_t",  "description": "MAVLink 版本"},
    ],
    "crc_extra": 50,
    "description": "心跳消息，1Hz 发送"
}
```

**飞行器类型（MAV_TYPE）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | GENERIC | 通用 |
| 1 | FIXED_WING | 固定翼 |
| 2 | QUADROTOR | 四旋翼 |
| 3 | COAXIAL | 共轴双桨 |
| 4 | HELICOPTER | 直升机 |
| 6 | GROUND_ROVER | 地面车辆 |
| 13 | VTOL | 垂直起降固定翼 |

**系统状态（MAV_STATE）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | UNINIT | 未初始化 |
| 1 | BOOT | 启动中 |
| 2 | CALIBRATING | 校准中 |
| 3 | STANDBY | 待机 |
| 4 | ACTIVE | 活跃（飞行中） |
| 5 | CRITICAL | 临界（低电量等） |
| 6 | EMERGENCY | 紧急（失控保护） |

### 1.2 SYS_STATUS (ID=1)

系统状态消息，包含传感器状态、电池电压等信息。

```python
SYS_STATUS = {
    "id": 1,
    "fields": [
        {"name": "onboard_control_sensors_present", "type": "uint32_t"},
        {"name": "onboard_control_sensors_enabled", "type": "uint32_t"},
        {"name": "onboard_control_sensors_health",  "type": "uint32_t"},
        {"name": "load",               "type": "uint16_t"},  # CPU 负载 (0-1000)
        {"name": "voltage_battery",    "type": "uint16_t"},  # 电池电压 (mV)
        {"name": "current_battery",    "type": "int16_t"},   # 电池电流 (cA)
        {"name": "battery_remaining",  "type": "int8_t"},    # 电量百分比 (-1=未知)
        {"name": "drop_rate_comm",     "type": "uint16_t"},  # 通信丢包率
        {"name": "errors_comm",        "type": "uint16_t"},  # 通信错误数
    ],
    "description": "系统状态信息"
}
```

**传感器标志位：**

| 位 | 传感器 | 说明 |
|----|--------|------|
| 0 | 3D_GYRO | 陀螺仪 |
| 1 | 3D_ACCEL | 加速度计 |
| 2 | 3D_MAG | 磁力计 |
| 3 | ABSOLUTE_PRESSURE | 气压计 |
| 6 | GPS | GPS |
| 10 | BATTERY | 电池 |
| 11 | RC_RECEIVER | 遥控接收 |

## 2. 飞行数据消息

### 2.1 ATTITUDE (ID=30)

姿态消息，包含 Roll、Pitch、Yaw 及角速度。

```python
ATTITUDE = {
    "id": 30,
    "fields": [
        {"name": "time_boot_ms", "type": "uint32_t"},  # 启动后时间 (ms)
        {"name": "roll",         "type": "float"},      # 横滚角 (rad)
        {"name": "pitch",        "type": "float"},      # 俯仰角 (rad)
        {"name": "yaw",          "type": "float"},      # 偏航角 (rad)
        {"name": "rollspeed",    "type": "float"},      # 横滚角速度 (rad/s)
        {"name": "pitchspeed",   "type": "float"},      # 俯仰角速度 (rad/s)
        {"name": "yawspeed",     "type": "float"},      # 偏航角速度 (rad/s)
    ],
    "description": "飞行器姿态"
}
```

**姿态角定义：**

```
          北 (Yaw=0)
           ↑
           │    ╱ 机头方向
           │   ╱
           │  ╱  Yaw (偏航角)
           │ ╱
  西←──────┼──────→东
           │
           │
           ↓
          南 (Yaw=π)

Roll (横滚角):     Pitch (俯仰角):
      ┌───┐              ┌───┐
      │   │ ← 0°         │   │ ← 0°
      └───┘              └───┘
      ╱───╲              ┌───╱
     ╱    ╲ → +Roll      │  ╱ → +Pitch
    ╱──────╲             └─╱
```

### 2.2 GPS_RAW_INT (ID=24)

GPS 原始数据消息。

```python
GPS_RAW_INT = {
    "id": 24,
    "fields": [
        {"name": "time_usec",      "type": "uint64_t"},  # 时间戳 (μs)
        {"name": "fix_type",       "type": "uint8_t"},   # 定位类型
        {"name": "lat",            "type": "int32_t"},   # 纬度 (degE7)
        {"name": "lon",            "type": "int32_t"},   # 经度 (degE7)
        {"name": "alt",            "type": "int32_t"},   # 海拔高度 (mm)
        {"name": "eph",            "type": "uint16_t"},  # 水平精度
        {"name": "epv",            "type": "uint16_t"},  # 垂直精度
        {"name": "vel",            "type": "uint16_t"},  # 地速 (cm/s)
        {"name": "cog",            "type": "uint16_t"},  # 地面航向 (cdeg)
        {"name": "satellites_visible", "type": "uint8_t"},  # 可见卫星数
    ],
    "description": "GPS 原始定位数据"
}
```

**GPS 定位类型（FIX_TYPE）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | NO_GPS | 无 GPS |
| 1 | NO_FIX | 有信号无定位 |
| 2 | FIX_2D | 2D 定位 |
| 3 | FIX_3D | 3D 定位 |
| 4 | DGPS | 差分 GPS |
| 5 | RTK_FLOAT | RTK 浮点解 |
| 6 | RTK_FIXED | RTK 固定解 |

**坐标单位转换：**

```python
# degE7 转换为度
def degE7_to_deg(degE7):
    return degE7 / 1e7

# 示例
lat_degE7 = 301234567  # 30.1234567° N
lat_deg = lat_degE7 / 1e7  # 30.1234567
```

## 3. 命令消息

### 3.1 COMMAND_LONG (ID=76)

通用命令消息，用于发送各种飞控命令。

```python
COMMAND_LONG = {
    "id": 76,
    "fields": [
        {"name": "param1",     "type": "float"},    # 参数1
        {"name": "param2",     "type": "float"},    # 参数2
        {"name": "param3",     "type": "float"},    # 参数3
        {"name": "param4",     "type": "float"},    # 参数4
        {"name": "param5",     "type": "float"},    # 参数5 (X)
        {"name": "param6",     "type": "float"},    # 参数6 (Y)
        {"name": "param7",     "type": "float"},    # 参数7 (Z)
        {"name": "command",    "type": "uint16_t"}, # 命令 ID (MAV_CMD)
        {"name": "target_system",    "type": "uint8_t"},
        {"name": "target_component", "type": "uint8_t"},
        {"name": "confirmation",     "type": "uint8_t"},
    ],
    "description": "通用命令消息"
}
```

### 3.3 COMMAND_ACK (ID=77)

```python
COMMAND_ACK = {
    "id": 77,
    "fields": [
        {"name": "command",       "type": "uint16_t"},  # 命令 ID
        {"name": "result",        "type": "uint8_t"},   # 结果 (MAV_RESULT)
```

**MAV_RESULT 结果码：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | ACCEPTED | 命令被接受 |
| 1 | TEMPORARILY_REJECTED | 临时拒绝（稍后重试） |
| 2 | DENIED | 命令被拒绝 |
| 3 | UNSUPPORTED | 不支持的命令 |

使用 `MESSAGE_INTERVAL` 命令调整消息发送频率：

```python

    param6=0,
    param7=0,
```

## 5. 消息解析示例

### 5.1 Python 解析示例

```python
from pymavlink import mavutil

# 创建连接
conn = mavutil.mavlink_connection('udp:127.0.0.1:14550')

# 等待心跳
print("等待心跳...")
conn.wait_heartbeat()
print(f"收到心跳: SYS={conn.target_system}, COMP={conn.target_component}")

while True:
    msg = conn.recv_match(blocking=True)

    if msg is None:
        continue

    msg_type = msg.get_type()

    if msg_type == 'HEARTBEAT':
        print(f"HEARTBEAT: type={msg.type}, "
              f"autopilot={msg.autopilot}, "
              f"base_mode={msg.base_mode}, "
              f"system_status={msg.system_status}")

    elif msg_type == 'ATTITUDE':
        import math
        roll_deg = math.degrees(msg.roll)
        pitch_deg = math.degrees(msg.pitch)
        yaw_deg = math.degrees(msg.yaw)
        print(f"ATTITUDE: roll={roll_deg:.1f}°, "
              f"pitch={pitch_deg:.1f}°, "
              f"yaw={yaw_deg:.1f}°")

    elif msg_type == 'GPS_RAW_INT':
        lat = msg.lat / 1e7
        lon = msg.lon / 1e7
        alt = msg.alt / 1000
        print(f"GPS: lat={lat:.7f}, lon={lon:.7f}, "
              f"alt={alt:.1f}m, sats={msg.satellites_visible}")

    elif msg_type == 'BATTERY_STATUS':
        voltage = msg.voltages[0] / 1000
        print(f"BATTERY: {voltage:.1f}V, "
              f"{msg.battery_remaining}%")
```

## 思考题

1. **HEARTBEAT 消息的作用是什么？如果地面站在 5 秒内未收到心跳，应该采取什么措施？**

2. **GPS_RAW_INT 中的坐标单位是 degE7（度的 10^7 倍），为什么不直接使用浮点数？**

3. **COMMAND_LONG 消息的 param1-param7 在不同命令中含义不同，这种设计有什么优缺点？**

4. **设计一个完整的解锁（ARM）流程，包括所有需要的消息和错误处理。**

5. **如何通过 MAVLink 消息判断飞控的健康状态？需要监控哪些关键消息？**

<details>
<summary>参考答案</summary>

**1. HEARTBEAT 的作用：**

- 检测系统在线状态（类似"保活"机制）
- 交换系统能力和状态信息
- 用于系统发现（地面站发现飞控）

5 秒未收到心跳：应进入"连接丢失"状态，尝试重新连接，或触发失控保护（failsafe）动作。

**2. degE7 的优势：**

- 整数精度：int32_t 可以表示 ±214° 的范围，精度 10^-7 度 ≈ 1.1cm
- 无浮点误差：整数运算精确
- 网络传输：整数比浮点数更紧凑
- 嵌入式友好：许多 MCU 没有硬件浮点单元

**3. COMMAND_LONG 的优缺点：**

优点：
- 统一的消息格式，减少消息类型数量
- 灵活，可扩展新命令
- 代码复用性高

缺点：
- 参数含义不明确，需要查阅文档
- 错误使用参数的风险高
- 不同命令的参数类型不同（有些是整数索引，有些是实际值）

**4. 解锁流程：**

1. 发送 HEARTBEAT 确认连接
2. 检查 SYS_STATUS 确认传感器健康
3. 检查 GPS 状态（至少 3D FIX）
4. 发送 COMMAND_LONG (MAV_CMD_COMPONENT_ARM_DISARM, param1=1)
5. 等待 COMMAND_ACK (result=0 表示成功)
6. 如果被拒绝，检查拒绝原因（可能需要 preflight 检查）

**5. 健康状态监控：**

关键消息：
- SYS_STATUS: 传感器健康状态、电池电量
- GPS_RAW_INT: GPS 定位质量
- ATTITUDE: 姿态是否稳定
- BATTERY_STATUS: 电池电压和电流
- STATUSTEXT: 飞控发出的警告和错误信息
- SERVO_OUTPUT_RAW: 舵机输出是否正常

</details>
