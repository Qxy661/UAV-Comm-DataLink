## 1. 多机通信核心公式

**一致性协议（Consensus Protocol）:**
$$x_i[k+1] = x_i[k] + \gamma \sum_{j \in \mathcal{N}_i} a_{ij}\big(x_j[k] - x_i[k]\big)$$

**通信图拉普拉斯矩阵:**
$$\mathbf{L} = \mathbf{D} - \mathbf{A}$$
其中 $\mathbf{D}$ 为度矩阵，$\mathbf{A}$ 为邻接矩阵。一致性收敛条件：图连通，即 $\lambda_2(\mathbf{L}) > 0$。

**集群协议容量上界（Gupta-Kumar）:**
$$\Theta = O\!\left(\frac{W}{\sqrt{N \log N}}\right)$$

**相关标准:**
- [MIL-STD-6016: Link 16 战术数据链](https://www.esd.whs.mil/portals/54/documents/FOISS/6016.pdf)
- [STANAG 5516: Link 22 北约改进数据链](https://nso.nato.int/natolive/stanag_detail.asp?id=STANAG%205516)

## 2. 无人机集群通信论文

### 论文 20: UAV Swarm Communication

**标题:** UAV Swarm Communication: Challenges and Solutions

**作者:** Bekmezci, Sahingoz

**年份/期刊:** 2013, Ad Hoc Networks

**研究问题:**
- 无人机集群通信的独特挑战
- 通信架构设计

**核心方法:**
- 网络拓扑分析
- 协议设计
- 性能评估

**主要贡献:**
- 集群通信架构
- 协议设计方法
- 性能分析框架

**关键公式:**

- **集群网络吞吐量上界（协议容量模型）:**
$$\Theta = O\!\left(\frac{W}{\sqrt{N \log N}}\right)$$
其中 $W$ 为信道带宽，$N$ 为节点数（Gupta-Kumar 定理在移动网络中的推广）。

- **端到端延迟:** $D_{\mathrm{e2e}} = D_{\mathrm{tx}} + D_{\mathrm{prop}} + D_{\mathrm{queue}} + D_{\mathrm{hop}} \cdot H$，其中 $H$ 为跳数。

**性能数据:**
- 20 架 UAV 的集群，单跳传输延迟约 2–5 ms，多跳（5 跳）延迟约 15–30 ms
- 自组织网络吞吐量随节点数增加而下降：10 节点时约 20 Mbps，50 节点时降至约 5 Mbps

**关键结论:**
- 集群通信比单机复杂
- 自组织能力关键
- 需要高效协议

**参考链接:**
- [Bekmezci et al., "Flying ad-hoc networks (FANETs): A survey", Ad Hoc Networks, 2013](https://doi.org/10.1016/j.adhoc.2012.12.004)

### 论文 22: Mesh Networking for UAV

**标题:** Mesh Networking for UAV: Architecture and Protocols

**作者:** Maxa, Rondony

**年份/期刊:** 2017, IEEE Aerospace Conference

**研究问题:**
- 无人机 Mesh 网络架构
- 协议设计

**核心方法:**
- 架构设计
- 协议开发
- 仿真验证

**主要贡献:**
- Mesh 网络架构
- 路由协议
- 性能评估

**关键公式:**

- **Mesh 网络端到端吞吐量:**
$$T_{\mathrm{e2e}} = \frac{W}{H} \cdot \min_{i \in \mathrm{path}} \log_2(1 + \mathrm{SNR}_i)$$
其中 $H$ 为跳数，瓶颈在最弱链路。

**性能数据:**
- 5 节点 UAV Mesh 网络，单跳吞吐量约 10–20 Mbps，多跳后降至约 3–8 Mbps
- 链路中断后重路由时间约 50–200 ms（取决于协议）

**关键结论:**
- Mesh 网络适合集群
- 路由协议关键
- 需要考虑移动性

**参考链接:**
- [Maxa et al., IEEE Aerospace Conference, 2017](https://doi.org/10.1109/AERO.2017.7943900)

## 3. 编队通信论文

### 论文 23: Formation Control Communication

**标题:** Communication-Aware Formation Control for UAV Teams

**作者:** Zhou, Liu

**年份/期刊:** 2020, IEEE Transactions on Control of Network Systems

**研究问题:**
- 通信感知的编队控制
- 通信与控制的协同

**核心方法:**
- 联合优化
- 通信约束建模
- 控制算法设计

**主要贡献:**
- 通信感知控制
- 联合优化框架
- 算法设计

**关键公式:**

- **编队通信图:** 用有向图 $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ 描述 UAV 间通信链路，$\mathcal{V}=\{1,\dots,N\}$ 为节点集，$\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}$ 为边集。

- **编队控制律（带通信约束）:**
$$u_i = -\sum_{j \in \mathcal{N}_i} \left[(p_i - p_j) - d_{ij}\right] + k_p(p_i^{\mathrm{des}} - p_i)$$
其中 $p_i$ 为位置，$d_{ij}$ 为期望相对位置，$p_i^{\mathrm{des}}$ 为期望编队位置，$k_p$ 为增益。

- **联合优化目标:**
$$\min_{\mathbf{p}, \mathcal{G}} \sum_{i} J_{\mathrm{ctrl},i}(\mathbf{p}) + \lambda \sum_{(i,j)\in\mathcal{E}} C_{\mathrm{comm}}(d_{ij})$$

**性能数据:**
- 编队间距从 50 m 增加到 200 m 时，通信中断概率从 <1% 增加到约 10–20%
- 通信感知编队控制相比纯位置控制，跟踪误差减少约 20–40%

**关键结论:**
- 通信影响控制性能
- 需要联合优化
- 编队几何重要

### 论文 24: Consensus for UAV Swarm

**标题:** Consensus-Based Formation Control for UAV Swarm with Communication Constraints

**作者:** Dong, Yu

**年份/期刊:** 2021, Automatica

**研究问题:**
- 通信约束下的编队一致性
- 分布式控制

**核心方法:**
- 一致性算法
- 通信约束处理
- 稳定性分析

**主要贡献:**
- 分布式控制算法
- 约束处理方法
- 稳定性证明

**关键公式:**

- **离散时间一致性协议:**
$$x_i[k+1] = x_i[k] + \gamma \sum_{j \in \mathcal{N}_i} a_{ij}\big(x_j[k] - x_i[k]\big)$$
其中 $x_i$ 为第 $i$ 架 UAV 的状态，$\mathcal{N}_i$ 为其邻居集合，$a_{ij}$ 为邻接矩阵元素，$\gamma$ 为步长。

- **矩阵形式:**
$$\mathbf{x}[k+1] = \mathbf{W} \mathbf{x}[k], \quad \mathbf{W} = \mathbf{I} - \gamma \mathbf{L}$$
其中 $\mathbf{L}$ 为通信图的拉普拉斯矩阵。一致性收敛条件：$\lambda_2(\mathbf{L}) > 0$（图连通）。

**性能数据:**
- 收敛时间与代数连通度 $\lambda_2(\mathbf{L})$ 成反比：$T_{\mathrm{conv}} \propto 1/\lambda_2$
- 通信延迟 > 100 ms 时，一致性误差增加约 30–50%
- 丢包率 10% 时，收敛时间增加约 1.5–2 倍

**关键结论:**
- 分布式控制有效
- 通信约束影响收敛
- 需要鲁棒性设计

### 论文 26: NOMA for UAV

**标题:** Non-Orthogonal Multiple Access for UAV Communications

**作者:** Liu, Li

**年份/期刊:** 2020, IEEE Transactions on Wireless Communications

**研究问题:**
- NOMA 在无人机通信中的应用
- 性能优势

**核心方法:**
- NOMA 建模
- 功率分配
- 性能分析

**主要贡献:**
- NOMA UAV 架构
- 功率分配算法
- 性能比较

**关键公式:**

- **NOMA 下行速率（两用户场景）:**
$$R_1 = \log_2\!\left(1 + \frac{\alpha_1 P |h_1|^2}{N_0 B}\right), \quad R_2 = \log_2\!\left(1 + \frac{\alpha_2 P |h_2|^2}{\alpha_1 P |h_2|^2 + N_0 B}\right)$$
其中 $\alpha_1 + \alpha_2 = 1$ 为功率分配系数（远端用户分配更多功率 $\alpha_1 > \alpha_2$），采用 SIC 解码。

**性能数据:**

| 方案 | 频谱效率 | 边缘用户速率 | 总吞吐量 |
|------|---------|------------|---------|
| OMA (OFDMA) | 1× | 基准 | 基准 |
| NOMA | 约 1.3–1.5× | 提升 20–40% | 提升 30–50% |

注：具体增益取决于信道条件和功率分配策略。

**关键结论:**
- NOMA 可提高频谱效率
- 功率分配关键
- 需要信道估计

## 5. 协作通信论文

### 论文 27: Cooperative UAV Communication

**标题:** Cooperative Communication for UAV: Relay and MIMO

**作者:** Li, Chen

**年份/期刊:** 2018, IEEE Transactions on Vehicular Technology

**研究问题:**
- 无人机协作通信技术
- 中继和 MIMO

**核心方法:**
- 中继协议
- MIMO 技术
- 性能分析

**主要贡献:**
- 协作通信架构
- 中继选择算法
- MIMO 增益分析

**关键公式:**

- **AF（放大转发）中继容量:**
$$C_{\mathrm{AF}} = \frac{1}{2} \log_2\!\left(1 + \mathrm{SNR}_1 + \frac{\mathrm{SNR}_1 \cdot \mathrm{SNR}_2}{1 + \mathrm{SNR}_1 + \mathrm{SNR}_2}\right)$$
其中 $\mathrm{SNR}_1$ 为源-中继信噪比，$\mathrm{SNR}_2$ 为中继-目的信噪比，系数 1/2 为正交时隙。

- **DF（解码转发）中继容量:**
$$C_{\mathrm{DF}} = \frac{1}{2} \min\!\left(\log_2(1+\mathrm{SNR}_1),\; \log_2(1+\mathrm{SNR}_2)\right)$$

**性能数据:**
- UAV 中继可将覆盖距离扩展 2–3 倍（相同发射功率下）
- 3 架 UAV 协作中继相比直传，吞吐量提升约 50–100%

**关键结论:**
- 协作可扩展覆盖
- 中继选择重要
- MIMO 可提高性能

### 论文 28: Multi-Hop UAV Relay

**标题:** Multi-Hop Relay for UAV: Routing and Resource Allocation

**作者:** Ruan, Wang

**年份/期刊:** 2021, IEEE Internet of Things Journal

**研究问题:**
- 多跳中继网络
- 路由和资源分配

**核心方法:**
- 路由算法
- 资源分配
- 联合优化

**主要贡献:**
- 多跳网络架构
- 路由算法
- 资源优化

**关键公式:**

- **多跳端到端容量上界:**
$$C_{\mathrm{e2e}} \leq \min_{i=1,\dots,H} C_i$$
其中 $C_i$ 为第 $i$ 跳的链路容量。

- **路由度量（ETX - Expected Transmission Count）:**
$$\mathrm{ETX} = \frac{1}{\prod_{i=1}^{H} p_i}$$
其中 $p_i$ 为第 $i$ 跳的包投递率。

**性能数据:**
- 最优中继数量通常为 2–4 跳（权衡覆盖扩展与延迟累积）
- 每增加一跳，端到端延迟增加约 2–5 ms，吞吐量下降约 15–25%

**关键结论:**
- 多跳可扩展距离
- 路由算法关键
- 需要联合优化

## 6. 安全通信论文

### 论文 29: Secure UAV Swarm Communication

**标题:** Secure Communication for UAV Swarm: Physical Layer Security

**作者:** Wang, Zhang

**年份/期刊:** 2020, IEEE Transactions on Information Forensics and Security

**研究问题:**
- 集群通信的安全问题
- 物理层安全

**核心方法:**
- 安全容量分析
- 波束成形
- 人工噪声

**主要贡献:**
- 安全通信架构
- 安全算法
- 性能分析

**关键公式:**

- **集群安全容量:**
$$C_s^{\mathrm{swarm}} = \max_{\mathbf{w}} \min_{e \in \mathcal{E}_e} \left[\log_2(1+\mathrm{SINR}_d(\mathbf{w})) - \log_2(1+\mathrm{SINR}_e(\mathbf{w}))\right]^+$$
其中 $\mathbf{w}$ 为波束成形向量，$\mathcal{E}_e$ 为窃听者集合。

**性能数据:**
- 集群协作波束成形可使安全容量提升约 3–5 倍（相比单机传输）
- 人工噪声功率占比 30% 时，窃听端 SNR 下降约 15–20 dB

**关键结论:**
- 物理层安全有效
- 波束成形可防窃听
- 需要信道信息
