## 13. 推荐阅读顺序

### 入门级（1-2 周）

```
1. Air-to-Ground Channel Model (2014) - 基础信道模型
2. Cellular-Connected UAV (2019) - 蜂窝 UAV 概述
3. UAV Communications for 5G and Beyond (2019) - 5G 综述
```

### 进阶级（2-4 周）

```
4. Channel Measurements and Models (2019) - 信道测量
5. On the Capacity of UAV Communication Links (2016) - 容量分析
6. MEC for UAV Applications (2020) - 边缘计算
7. Network Slicing for UAV Services (2021) - 网络切片
```

### 高级（4-8 周）

```
8. Physical Layer Security for UAV (2020) - 物理层安全
9. UAV Swarm Communication (2013) - 集群通信
10. Distributed Control for UAV Swarm (2020) - 分布式控制
11. Blockchain for UAV Communication (2021) - 区块链
```
